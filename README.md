# Math Tutor Pro - Educational Game

An interactive educational learning game designed to help students practice reflexes and decision-making through engaging gameplay.

## Features

- 📚 Educational gameplay mechanics
- 📈 Progressive difficulty levels for skill development
- 🏆 Progress tracking and scoring system
- 🎨 Clean, professional interface
- 📱 Optimized for school computers and tablets
- ⌨️ Simple keyboard and mouse controls

## Educational Value

This tutorial helps students develop:
- **Hand-eye Coordination** - Quick visual response times
- **Decision-Making Skills** - Fast reactions to changing conditions
- **Problem-Solving** - Adapting strategies to increasing difficulty
- **Persistence** - Learning from mistakes and improvement

## How to Use

1. Click the **Start Tutorial** button to begin
2. Press **SPACE** or **CLICK** to continue through the tutorial
3. Navigate through progressive challenges
4. Track your learning progress with the scoring system
5. Complete the tutorial to test your developed skills

## Controls

- **SPACE BAR** - Continue through tutorial
- **MOUSE CLICK** - Continue through tutorial  
- **START BUTTON** - Begin the tutorial
- **TRY AGAIN BUTTON** - Restart the tutorial

## Game Mechanics

- Each completed tutorial segment adds to your progress
- Every 100 progress points increases the tutorial level
- Difficulty scales to match your skill level
- Challenges appear at varying heights
