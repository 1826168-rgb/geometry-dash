# Geometry Dash Game

A fun, interactive Geometry Dash-inspired web game built with HTML5, CSS, and JavaScript.

## Features

- 🎮 Simple and addictive gameplay
- 📈 Progressive difficulty levels
- 🏆 Score tracking
- 🎨 Beautiful gradient UI
- 📱 Responsive design
- ⌨️ Keyboard and mouse controls

## How to Play

1. Click the **Start Game** button to begin
2. Press **SPACE** or **CLICK** to make your cube jump
3. Avoid the red obstacles
4. Survive as long as possible to increase your score
5. The game gets progressively harder!

## Controls

- **SPACE BAR** - Jump
- **MOUSE CLICK** - Jump
- **START BUTTON** - Begin the game
- **RESTART BUTTON** - Play again after game over

## Game Mechanics

- Each avoided obstacle gives you 10 points
- Every 100 points increases the level and difficulty
- Game speed increases with each level
- Obstacles spawn at varying sizes and heights
